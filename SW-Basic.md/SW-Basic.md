## 프로토콜 (= 규칙/약속)
- 프로토콜은 통신규칙이다
    - 통신규칙: 컴퓨터가 대화할때 지켜야하는 규칙 (사람이 대화시 지키는 규칙과 비슷)

### 프로토콜이 필요한 이유
- 데이터 형식이 제각각
  - 한 컴퓨터는 이름을 먼저보내고 다른 컴퓨턴 나이를 먼저 보내면 해석이 꼬인다.
- 전송중 오류처리 불가
  - 데이터가 중간에 깨지거나 일부만 도착했을 때 다시 보내야 하는지, 버려야 하는지 기준이 필요
- **서로 다른 회사의 장비끼리 통신불가**
    - 서로 통신하려면 공통규칙 필요

## 프로토콜 핵심구성 요소

### 구문(Syntax)
- 데이터의 형식
    - 어떻게 생긴 형태로 보낼건지를 정함
    
- 첫 번째 칸에는 주소
- 두 번째 칸에는 명령어
- 세 번째 칸에는 실제 데이터
```
[첫 번째 칸] [두 번째 칸] [세 번째 칸]
```
#### 첫 번째 칸 = 주소
"이 데이터를 어디로 보낼지"

- 목적지 정보
- 누가 받을지 결정

📌 예시

- IP 주소: 192.168.0.1
- URL: google.com

👉 현실 비유

택배에서 **배송지 주소**라고 보면 된다

#### 두번째 칸 = 명령어
"무슨 작업을 할지"

- 데이터를 조회할지
- 저장할지
- 삭제할지

📌 예시

- GET → 데이터 조회
- POST → 데이터 생성
- DELETE → 삭제

👉 현실 비유

택배에서 **“이 물건 어떻게 처리할지”**

- 전달만 할지
- 반품할지

#### 세번째 칸 = 실제 데이터
"진짜 보내고 싶은 내용"

- 사용자 정보
- 파일 내용
- 메시지

📌 예시

```
{
  "name":"홍길동",
  "age":20
}
```

#### 총

```
[주소]        [명령어]   [데이터]
192.168.0.1   POST       { "name": "홍길동" }
```

👉 해석

- 192.168.0.1로 보내고
- POST 요청을 하고
- 홍길동 데이터를 전달한다
