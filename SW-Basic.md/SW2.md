## 이행함수 종속

- A -> B, B -> C면 A -> C가 되는 관계

- 학번  학과코드  학과명

- 학번 -> 학과코드, 학과코드 -> 학과명 일때 학번 -> 학과명

- **수정 이상**이 발생한다.

## 이상현상이란?
- 데이터베이스 설계가 잘못되어 데이터를 `삽입`, `수정`, `삭제`할 때 비정상적인 문제가 발생하는 현상

### 삽입 이상

- 데이터를 추가하려고 할 때, 필요 없는 데이터까지 강제로 넣어야 하는 문제
- -----------------------
- 학생번호 학생명 과목명 교수명
- 1  김철수 DB  이교수
- NULL  NULL  PYTHON 김교수
- -----------------------
- 과목만 추가하고싶은데 학생 정보까지 필요함

### 수정 이상

- 같은 데이터가 여러 번 저장되어 일부만 수정하면 데이터의 일관성이 사라지는 문제
학생번호 학생명 과목명 교수명 강의실
- -----------------------
- 1  김철수 DB  이교수 401
- 2  이영희 DB  이교수 301
- 3  박민수 DB  이교수 301
- -----------------------
- UPDATE TABLE
- SET 강의실 = '401'
- WHERE 학생번호 = 1;
- -----------------------
### 삭제 이상

- 데이터를 삭제할 때, 유지해야 할 다른 정보까지 같이 삭제되는 문제
- -----------------------
- 학생번호 학생명 과목명 교수명
-    1   김철수 DB  이교수

- 1명이 수강을 하고 있는데 김철수가 수강 철회

- 학생정보가 삭제 되나 DB과목 존재 정보가 같이 삭제됨

## MySQL

## 관계형데이터베이스(RDBMS)

- 테이블 형태로 데이터를 관리(릴레이션)
- 행(ROW) : 가로 데이터셋 (한 건의 데이터) 튜플
ㄴ 행의 개수 : 카디널리티
- 열(COLUMN) : 세로 데이터셋(한 가지의 데이터) 속성(attribute)

## SQL이란?

- 데이터베이스에 저장된 데이터를 다루기 위한 언어(추가,조회,수정,삭제)

### SQL의 종류
DDL: 데이터베이스 객체를 조작하는 SQL

- CREATE : 데이터 베이스 객체를 생성할 때 사용
- ALTER : 수정할 때 사용
- DROP : 삭제할 때 사용

DML : 테이블 내의 데이터를 조작하는 SQL

- SELECT : 테이블 내의 데이터를 조회하여 보여준다.
- INSERT : 테이블에 데이터를 추가한다.
- UPDATE : 테이블 내의 데이터를 수정한다.
- DELETE : 테이블 내의 데이터를 삭제한다.

DCL : 권한관리 명령어

- GRANT : 권한을 주는 명령어
- REVOKE : 권한을 회수하는 명령어
TCL : 트랜잭션 제어
- COMMIT
- ROLLBACK

- 트랜잭션 : 여러 SQL 작업을 하나의 작업 단위로 묶는 것
- -----------------------
- EX) 계좌이체
- A계좌에서 10만원 이체
- B계좌에서 10만원 입금

- MySQL은 기본적으로 AUTO COMMIT 상태로 되어있다.

- START TRANSACTION; - 임시로 반영이 됨
- 쿼리문1
- 쿼리문2

- ROLLBACK;
- -----------------------

### 제약조건

- 테이블에 잘못된 데이터가 들어가지 않도록 막는 규칙
PK - PRIMARY KEY (기본키) NULL 불가, 중복 불가
NOT NULL - 값을 비워두지 마라
UNIQUE - 중복된 값을 넣지마라
FK - FOREIGN KEY (외래키) 다른 테이블의 기본키를 참조하는 제약조건
ㄴ 없는 데이터를 참조하지 못하게 하는 규칙

CHECK - 특정 값만 조건을 만족하도록 제한하는 제약조건
DEFAULT - 값을 입력하지 않았을 때 자동으로 들어갈 기본값 설정

### 모델링

- 현실세계의 데이터를 데이터베이스 구조로 설계하는 과정
요구사항분석
개념모델링 - 엔티티의 결정 (ERD 작성)
논리모델링 - ERD를 보고 자료형이나 제약조건 설정 , 정규화(1 ~ 5차)
물리모델링 - 실제 테이블로 만드는 과정

### SQL함수
단일 행 함수 - 1개의 행 값이 함수에 적용되어 1개의 행을 반환하는것
집계 함수 - 1개 이상의 행 값이 함수에 적용되어 1개의 행을 반환한다.

### 문자함수
LENGTH() : 바이트 수 반환
CHAR_LENGTH() : 글자 수 반환
UPPER(),LOWER() : 대문자로 변환, 소문자로 변환
TRIM(),LTRIM(),RTRIM() : 양쪽 공백 제거, 왼쪽공백제거, 오른쪽공백제거
LPAD(),RPAD() : 문자열의 자리수를 지정, 남으면 특정문자열로 채운다.
SUBSTRING(), SUBSTR(), MID() : 문자열 자르기
※ MySQL에서 인덱스는 1부터 시작한다.

LEFT(), RIGHT() : 문자열을 왼쪽/오른쪽부터 내가 원하는만큼 자른다.
INSTR() : 문자열의 위치번호 찾기
CONCAT() : 나열된 문자열의 연결
REPLACE() : 문자열에서 특정 문자열을 다른 문자열로 교체(등장하는 모든 문자열을 교체해준다.)
ㄴ없으면 원래 문자열 그대로를 반환한다.
SUBSTRING_INDEX(문자열,구분자,개수) : 문자열을 특정 구분자를 기준으로 잘라서 원하는 부분만 가져오는 함수

- 내림차순(DESC) : 큰거 -> 작은거

SELECT절의 맨뒤에 적는다.

SELECT 컬럼명

오름차순
숫자 : 작은값 -> 큰값
문자 : ㄱ -> ㅎ, A -> Z
날짜 : 오래된 날짜 ->  최신 날짜

여러개의 컬럼으로 정렬할 수 있다.
ORDER BY 정렬컬럼1 정렬방식, 정렬컬럼2 정렬방식...;

순위를 정하는 함수 (윈도우 함수)

- ROW_NUMBER() : 무조건 1,2,3,4 처럼 번호를 붙인다.
- RANK() : 공동 순위를 인정하고, 다음 순위를 건너뛴다.
- DENSE_RANK() : 공동 순위를 인정하지만, 다음 순위를 건너뛰지 않는다.
- NTILE(n) : 데이터를 n개의 그룹으로 나눈다.
- PERCENT_RANK() : 상대적인 순위 비율을 구한다.

UNIQUE 제약조건도 자동으로 인덱스를 만든다.

인덱스의 장점

1. SELECT 속도가 향상된다.

- 검색 조건에 INDEX가 있으면 조회 속도가 빨라질 수 있다.

2. ORDER BY 성능 향상

- 정렬을 빠르게 할 수 있다.

인덱스의 단점

1. 저장공간이 추가로 필요하다

- 인덱스는 별도의 자료구조이기 때문에 테이블 데이터를 저장하는 곳외에 인덱스 공간이 추가로 필요하다.

2. INSERT가 느려질 수 있다.

- 데이터를 추가할 때 테이블에만 넣는것이 아니라 인덱스도 같이 갱신해야 한다.

3. UPDATE가 느려질 수 있다.

- 인덱스가 걸린 컬럼을 수정하면 인덱스도 다시 정리해야 한다.

4. DELETE가 느려질 수 있다.

- 데이터를 삭제할 때도 인덱스에서 해당 값을 정리해야 한다.
