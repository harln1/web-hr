# 2026-04-20 (윈도우 명령어)
## 파일/폴더 관리 명령어

### mkdir 폴더명 : 
- 폴더의 생성

### cd 경로 : 
- 폴더의 이동

## 파일 목록 확인
### dir : 
- 현재 폴더의 파일 목록을 출력

## 파일 삭제
### del 파일명

## 폴더 삭제
### rmdir 폴더명 /s /q
- /s : 내부 파일까지 삭제
- /q : 확인 없이 삭제

## ip주소 확인
### ipconfig

## 네트워크 연결확인
### ping 주소 : 
- 인터넷 연결 테스트

## 실행중인 프로세스 확인
### tasklist

## 현재 사용자 확인
### whoami

## 입력한 내용을 그대로 출력하는 명령어
### echo 내용

## 파일만들 때 사용하는 echo
### echo 내용 > 파일명 : 
- 파일을 만들고 안에 내용을 작성해준다.
### echo. : 
- 빈 줄 출력

> : 덮어쓰기
>> : 추가쓰기

### type : 
- 파일에 들어있는 내용을 터미널에 출력하는 기능

- 로그 확인
- 설정파일 확인
- 간단한 텍스트 내용 확인
type 파일명1, 파일명2 : 여러개의 파일을 이어서 출력할 수 있다.

type 파일명1 > 파일명2 : 파일명1의 내용을 파일명2로 저장할 수 있다.

type 파일명1,파일명2 > 파일명3 : 두 파일을 하나로 합친다.

type con : 키보드에서 값을 입력받아 출력
ctrl + z 누르고 엔터치면 종료된다.

type con > 파일명 : 키보드에서 값을 입력받아 파일에 저장할 수 있다.
