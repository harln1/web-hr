## apt
- 우분투에서 프로그램을 관리하는 도구이다.
- 정확히는 패키지 관리자 라고 부른다.

- 프로그램
- 라이브러리
- 설치파일의 묶음
- 업데이트 파일

- 윈도우에서는 인터넷에 접속하여 .exe파일을 직접 다운로드해서 설치한다.

- 우분투는 apt를 통해 설치를 한다.

- `update` : 패키지 목록 정보를 최신으로 갱신하는것

- `sudo apt update` : apt가 가서 다운받는 저장소의 목록을 갱신한다.

설치 목록이 오래됐을 수 있기 대문이다.
설치 오류가 날수도 있다.
구버전을 설치하게 될 수도 있다.

저장소에서 정보를 받아와야 하므로 인터넷이 연결되어 있어야 한다.

시스템 패키지 정보에 영향을 주기 때문에 보통 sudo를 붙여야 한다.

## 운영체제별로 명령어가 좀 다름
### 윈도우
- 명령 프롬프트

- 전통적인 Windows 명령어를 사용한다.
PowerShell
- Microsoft가 만든 최신 쉘
- 객체 기반 명령어 사용
- Linux 스타일 명령어를 일부 지원

- `dir` : 목록을 볼 수 있다
- `cd` : 디렉터리 이동 ( cd 경로)
- `copy` : 파일 복사 (copy 원본파일명 복사파일명)
- `move` : 파일 이동 (move 파일명 경로)
- `del `: 삭제 (del 파일명)
- `mkdir` : 디렉터리 생성(mkdir 폴더명)
- `type` : 파일에 들어있는 내용 출력(type 파일명)

- `> `: 출력 결과를 파일에 저장(dir > 파일명)
- `cls` : 화면 지우기
- `ipconfig` : IP 주소 및 네트워크 정보 확인
- `ping` : 네트워크 연결상태 테스트 (ping google.com)

### 리눅스 명령어

- `ls` : 현재 위치의 파일 및 디렉터리 목록 출력
ㄴ ls [옵션] [경로]

- `ls -l(long format)` : 상세 정보 출력
- `ls -a(all)` : 숨김 파일까지 출력(숨김파일은 .으로 시작을 한다.)
-` ls -lh(human readable) `: 파일 크기를 사람이 보기 쉽게 표시
- `ls -R `: 하위 폴더까지 전부 출력
- `cd` : 디렉터리 이동 (cd 경로)
- `cp` : 파일 또는 디렉터리 복사
- `mv` : 파일 이동 또는 이름 변경
- `rm` : 파일 삭제
- `rmdir` : 폴더 삭제 (내용이 있는 폴더 삭제 rm -r 폴더명)
- `cat` : 파일 내용을 출력 (cat 파일명)

- `>` : 명령어 실행 결과를 파일로 저장(ls > list.txt)
- `alias` : 자주 사용하는 명령어를 별칭으로 설정
ㄴ alias 별칭='명령어'
- `clear `: 화면을 지운다.
- `pwd` : 현재 위치 확인
- `touch` : 파일을 새로 만들거나, 기존 파일의 시간 정보를 변경할 때 사용하는 명령어

컴퓨터를 여러 사용자가 함께 쓰거나, 서버에서 여러 프로그램이 동시에 동작하면 아무나 파일을 읽고, 수정하고, 실행할 수 있으면 큰 문제가 생긴다.

누가 접근하는가
user : 파일의 소유자
group : 파일이 속한 그룹
other : 그 외 모든 사용자

무엇을 할 수 있는가
권한의 종류는 3가지 이다.
r : read, 읽기
w : write, 쓰기
x : execute, 실행

어디에 적용이 되는가

- 일반 파일
- 디렉터리(폴더)

파일에서의 r,w,x의 의미
r(read)

- 파일의 내용을 읽을 수 있다.
- 텍스트 파일 열기
- cat을 이용하여 내용 보기
- 프로그램이 파일 내용 읽게하기

w(write)
파일의 내용을 수정할 수 있다.

- 내용 추가
- 내용 삭제
- 내용 덮어쓰기

x(execute)

- 파일을 실행할 수 있다.
- 쉘 스크립트 실행
- 실행파일 실행

디렉터리에서 r,w,x의 의미
r : 디렉터리 안에 어떤 파일이 있는지 목록을 볼 수 있다.
w : 디렉터리 안에서 파일 생성, 삭제, 이름 변경
x : 디렉터리 안으로 들어갈 수 있는 권한

- rw- r-- r--
첫글자 : 파일의 종류
- : 일반 파일
d : 디렉터리
l : 링크

rw- : 소유자는 읽기, 쓰기만 가능하다.
r-- : 그룹은 읽기만 가능
r-- : 다른 사용자는 읽기만 가능

권한을 숫자로도 표현할 수 있다.
우분투에서는 권한을 문자 대신 숫자로 표현하기도 한다.

각 권한에 숫자를 부여한다.
r = 4
w = 2
x = 1

이 값을 더해서 표현한다.
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2 = 6
r-- = 4
r-x = 4 + 1 = 5
