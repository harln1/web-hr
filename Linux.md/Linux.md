## apt
- 우분투에서 프로그램을 관리하는 도구이다.
- 정확히는 패키지 관리자 라고 부른다.

- 프로그램
- 라이브러리
- 설치파일의 묶음
- 업데이트 파일

- 윈도우에서는 인터넷에 접속하여 .exe파일을 직접 다운로드해서 설치한다.

- 우분투는 apt를 통해 설치를 한다.

- `update` : 패키지 목록 정보를 최신으로 갱신하는것

- `sudo apt update` : apt가 가서 다운받는 저장소의 목록을 갱신한다.

설치 목록이 오래됐을 수 있기 대문이다.
설치 오류가 날수도 있다.
구버전을 설치하게 될 수도 있다.

저장소에서 정보를 받아와야 하므로 인터넷이 연결되어 있어야 한다.

시스템 패키지 정보에 영향을 주기 때문에 보통 sudo를 붙여야 한다.

## 운영체제별 주요 터미널과 그 특징

**1. Windows (윈도우)**

윈도우는 과거와의 호환성을 위한 도구와 현대적인 관리 도구가 공존합니다.

- **명령 프롬프트 (CMD):**
  - **특징:** MS-DOS 시절부터 내려온 전통적인 인터페이스입니다.
  - **용도:** 간단한 시스템 설정, 구형 배치 파일(.bat) 실행.
  - **주요 명령어:** `dir` (목록 확인), `cd` (이동), `copy` (복사), `ipconfig` (네트워크 확인).
- **PowerShell (파워쉘):**
  - **특징:** .NET 프레임워크 기반의 강력한 스크립트 환경입니다. 텍스트가 아닌 **'객체(Object)'** 단위로 데이터를 처리합니다.
  - **용도:** 시스템 자동화, 클라우드 관리, 복잡한 관리 작업.
  - **주요 명령어:** `Get-ChildItem` (ls와 유사), `Set-ExecutionPolicy` (권한 설정).

---

**2. Linux & macOS (유닉스 계열)**

- 두 운영체제는 뿌리가 비슷하여 명령어 구조가 매우 유사합니다.

- **Bash / Zsh (터미널):**
  - **특징:** **'텍스트 스트림'** 기반입니다. 모든 것을 파일로 간주하며, 작고 강력한 도구들을 파이프(`|`)로 연결해 사용합니다. (macOS는 현재 Zsh가 기본입니다.)
  - **용도:** 개발 환경 구축, 서버 운영, 오픈소스 도구 활용.
  - **주요 명령어:** `ls` (목록 확인), `cd` (이동), `cp` (복사), `ifconfig` 또는 `ip addr` (네트워크 확인).

- 파일을 만들면서 동시에 내용 편집까지 하겠다는 뜻입니다.
- cat (파일명).txt -> 내용편집 완료후 내용 잘 써 졌는지 바로확인

### Vim 핵심 명령어 요약
**기능 명령어 설명**

-  `i` ->  현재 커서 위치에서 글쓰기 시작 (Insert 모드)
-  `dd`-> 한 줄 삭제
- `x` -> 한 글자 삭제
- `yy`-> 한줄 복사
- `p` -> 커서 밑줄에 붙여넣기가 된다
- `u` ->되돌리기 , 방금 한 실수 취소 (Undo)
- `Esc`->명령 취소, 입력 모드에서 빠져나와 명령 대기 상태로 이동
- `wq` ->저장 후 종료,저장(w)하고 창 닫기(q)
-  `q!` ->저장 안 하고 종료
- `set number` ->행 번호 추가 (esc누르고 쓰기)
- `set nonumber` ->행의 번호 삭제/숨겨진다
- `:%s/기존단어/바꿀단어/g` ->치환 / g: 같은줄에 있는 모든 단어를 다 바꿔줌

## 사용자 생성 

1. 사용자 생성(주로 권장되는 방식)
- adduser는 비밀번호와 홈 디렉터리를 자동으로 설정해줘서 편리합니다.
- 명령어: sudo adduser [사용자명]
- 예시: sudo adduser minsu

2. 사용자 삭제
- 삭제할 때는 홈 디렉터리(파일들)까지 지울지 결정해야 합니다.
- 계정만 삭제: sudo deluser [사용자명]

3. 사용자 목록 확인
- 사용자가 잘 만들어졌는지, 혹은 지워졌는지 확인할 때 씁니다.
- 명령어: cut -d: -f1 /etc/passwd
- 특정 사용자만 검색: id [사용자명]

4. 사용자에게 관리자(sudo) 권한 주기
- 새로 만든 사용자가 sudo 명령어를 쓸 수 있게 하려면 이 설정이 필요합니다.
- 명령어: sudo usermod -aG sudo [사용자명]
