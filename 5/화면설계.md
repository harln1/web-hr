# 2026/6/5
## UI(사용자 인터페이스)
- 사용자가 제품과 상호작용하는 시각적인 요소와 디자인을 의미
- 버튼 디자인, 아이콘, 색상 구성 등이 UI 의 요소에 해당
- UI는 사용자가 소프트웨어를 어떤 관점에서 보고 어떻게 조작하는지에 중점을둔다

## UX (사용자 경험)
- 사용자가 소프트 웨어를 사용하며 느끼는 전체적인 경험을 의미
- 예를들어 웹을 사용하면서 느끼는 만족도,편의성,효율성 등이 UX에 해당한다
- UX는 사용자가 소프트웨어를 통해 무엇을 얻고 느끼는지에 중점을 둔다

### UI/UX 구성요소

- UI 구성요소
    -
- 시각적 디자인: 색상, 타이포그래피, 레이아웃, 아이콘 등 사용자가 화면에서 보는 모든요소
- 상호작용 디자인: 버튼클릭,스와이프등 사용자의 조작에 대한 반응
- 정보구조 : 콘텐츠의 구성 및 분류

- UX 구성요소
    -
- 사용성: 사용자가 소프트웨어를 얼마나 쉽게 이용할 수 있는지 정도
- 유용성: 소프트웨어가 사용자의 요구사항을 얼마나 충족하는지 정도
- 매력도: 소프트웨어가 사용자에게 얼마나 매력적인지 정도
- 접근성: 다양한 사용자가 소프트웨어를 얼마나 쉽게 이용할 수 있는지 정도
- 신뢰성: 소프트웨어에 대한 사용자의 믿는 정도

### UI/UX 의 관계
- 서로 밀접하게 관련이 있긴하다
- UX를 위해서는 좋은  UI가 필수지만, 좋은 UI가 항상 좋은 UX를 보장하지는 않는다.
    - 예를들어 멋진 버튼이 있어도 사용하기가 불편하다면 좋은 UX라고 할 수 없다
    - 사용하기 편리한 화면이라도 디자인이 매력적이지 않다면 좋은 UX 를 제공하기 어렵다
- UI 와 UX 는 서로 보완하며 사용자의 만족도를 높이는 데 기여한다.
